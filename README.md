## 🚀 Quick Start (Opening the Portfolio)

### Option 1: Direct in Browser
Simply double-click [`index.html`](file:///C:/Users/Shubham/.gemini/antigravity/scratch/got-portfolio/index.html) or [`standalone.html`](file:///C:/Users/Shubham/.gemini/antigravity/scratch/got-portfolio/standalone.html) to view it immediately in Chrome, Edge, Brave, or Firefox.

### Option 2: Local HTTP Server (Python)
Run the following in PowerShell:
```powershell
cd C:\Users\Shubham\.gemini\antigravity\scratch\got-portfolio
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
